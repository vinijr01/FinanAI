# Origem das imagens

As capturas do dashboard foram obtidas da interface gerada pelo código existente
no workflow Dashboard. Não houve redesenho da interface nem geração de telas por IA.

Para preservar os dados do grupo de testes, a renderização foi feita localmente
com um usuário, movimentações, metas e lembretes fictícios.

- dashboard-visao-geral.jpg: resumo do mês e gráficos.
- dashboard-lancamentos.jpg: lista de transações e filtros.
- dashboard-lembretes.jpg: compromissos e filtros.
- dashboard-metas.jpg: interface de metas já presente no código.
- arquitetura.png: diagrama produzido a partir das conexões dos três fluxos.

Os valores das capturas não são métricas do produto nem dados de seus participantes.
O nome FinanAI é provisório.

A prévia executável permanece em ambiente privado. Este repositório inclui
somente capturas estáticas, diagramas e documentação de apresentação.
